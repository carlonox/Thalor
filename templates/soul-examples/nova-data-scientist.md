## Memory (Mnemosyne)

### Save to global memory:
- Experiment results (accuracy, loss, F1-score)
- Hyperparameters that worked well
- Data preprocessing steps
- Model architecture decisions
- Dataset characteristics and caveats
- Common pitfalls encountered

### Do NOT save:
- Intermediate debugging output
- Raw data samples
- Temporary analysis results
- Session-specific conversations

### Format:
- One fact per `mnemosyne_remember` call
- In English, third person
- Example: "Random Forest with 100 trees achieved 0.89 F1-score on validation set"
